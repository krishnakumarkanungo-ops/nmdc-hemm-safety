HARDWARE SENSOR INGRESS & SERIAL BRIDGE

You can stream live sensor packets directly from an ESP32 microcontroller, Raspberry Pi, or USB Serial Bridge to this application.

REST INGRESS ENDPOINT:
POST http://localhost:8000/api/telemetry/ingress
EXAMPLE PYTHON HARDWARE BRIDGE / SENSOR FEEDER:
import requests, time

payload = {
  "vehicle_id": "HEMM-DUMP-07",
  "speed_kmh": 14.5,
  "heading_deg": 182.0,
  "gps": {"lat": 18.7155, "lng": 81.2538, "altitude_m": 1220.0},
  "radar": {"target_detected": True, "distance_m": 4.8, "relative_speed_kmh": -3.2},
  "collision_state": "CRITICAL",
  "berm_left_m": 3.8,
  "berm_right_m": 4.1
}

requests.post("http://localhost:8000/api/telemetry/ingress", json=payload)
